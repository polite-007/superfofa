# super-fofa v2.0

## 新增

- **查询卡片视图**：查询页新增卡片/列表切换，卡片采用单列宽卡布局；左侧展示标题、域名、位置、ASN/组织、系统服务、产品、更新时间，右侧展示 Header / Banner / Certificate；Header / Banner 默认显示固定高度预览，内容过长时展开查看。
- **左侧聚合面板**：卡片模式新增协议、域名、标题、国家/地区、端口 Top 10 聚合；支持国家/地区下钻、点击追加查询条件、独立加载与失败重试。
- **卡片字段配置**：按个人版 / 专业版 / 商业版 / 企业版四级会员权限过滤字段，最多 12 项；默认 11 项（含 TLS 版本），配置持久化。
- **正文查看**：商业版及以上且勾选正文时，卡片左下角提供「查看正文」按钮，弹窗展示正文纯文本并支持复制。
- **卡片跳转**：点击卡片非交互区域或 host 跳转站点 / 主机画像；host 右侧提供复制和跳转按钮。
- **代码开源**：Release 新增源代码压缩包（tar.gz / zip），源码随版本公开。

## 优化

- 查询每页条数改为 10 / 20 / 30 / 50，默认 10。
- 卡片字号、间距、圆角整体放大；右上角类型、协议、status_code 徽章同步放大。
- 左侧聚合栏字号与卡片信息区一致，调整面板顶部留白与分组排版。
- status_code 只展示 100–599 的合法 HTTP 状态码，0/非法值不再显示。
- Header / Banner 内容区底部与主机画像 / 正文操作行对齐。

## 修复

- 修复 host 本身已带端口时重复拼接出 `ip:port:port` 的问题。
- 修复卡片标题缺失/回退错误、卡片边框发虚、正文块重复展示等问题。
